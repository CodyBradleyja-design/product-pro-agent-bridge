# T20261119-001：桌面接收器 Windows 版一期

## 任务目标
按已确认方案（~/workspace/goals/06/files/desktop-receiver-sync-plan/desktop-receiver-sync-plan.md）做桌面接收器 Windows 版一期：可安装、可登录、可逐个授权本机微信、可手动同步，供 06 客户部用。

## 背景
- 入口已就绪：福珑手机版下载中心已建（网站版顶栏右上角＋「我的」菜单两处），下载按钮目前显示「待发布」，等本任务产出安装包后再上架。
- 方案状态：2026-11-19 用户已确认，按方案开工。
- 数据流：电脑端接收器 → 用户自己电脑本地 → 手机端一次授权后直接读电脑本地数据。

## 执行范围（归 WorkBuddy，Windows 本机执行）
1. 做 Windows 版接收器一期：安装到桌面，用用户账号登录；未登录时不检索微信、不读取数据。
2. 登录后点「客户」，里面设一个小的「更新」按钮；点更新才触发本地读取，不做自动抓取。
3. 检索本机已登录的微信账号（一个或多个），逐个点授权：如先授权「卖黄金的小迪」，点一下即可；想授权另一个再单独点那个；多个都点一遍就全同步上来。先接「艾迪」微信。
4. 授权后把该微信的聊天记录、联系人等信息同步上来，供客户部分析、建档、出维护策略、设提醒、生成近 30 天待关注清单。
5. 每次授权先弹滚动声明，告知用户：所有内容我方都不看，数据都保存在用户自己的机器里；声明滚动展示，用户看满 3 秒后才能继续授权。
6. 数据只存用户自己电脑本地，我方不看不存；电脑断网时手机端显示已离线、只能看缓存，恢复网络后恢复读取。
