# T20261115-002 001 的 Tailscale 登进服务器所在的网络（方案 A）

**任务目标**

在店里 Windows 电脑 001（吴凡001）上，把 Tailscale 登录/切换到服务器所在的网络，让服务器与 001 互通，为产品部爱心缓存拉图打通路。

背景：阿里云服务器已装 Tailscale 1.104.7，已加入网络，节点 IP 100.120.230.0，账号是 CodyBradleyja-design@。001 当前不在这个网络里（ping 报 no matching peer），不是没开机，是账号不同或从未加入。用户已定方案 A：001 登进这个网络，服务器不动。

**执行范围**

只动 001 本机上的 Tailscale。不改服务器上任何东西、不动阿里云、不改任何网站代码。授权链接发给用户本人点授权，不要替用户输任何账号密码。

**执行要求**

1. 先查现状：`tailscale version`（没装就用官方安装包先装好）、`tailscale status`，记下 001 当前登录的账号与节点 IP。
2. 让 001 加入服务器的网络：跑 `tailscale up`；如果当前已登录别的账号，先 `tailscale logout` 再 `tailscale up`。
3. `tailscale up` 会给出授权链接——把链接发给用户，由用户在浏览器里用 CodyBradleyja-design@ 账号点授权。等用户说授权完了再继续，不要自己猜、不要跳过这步。
4. 授权完成后验证：`tailscale status`，确认 001 与服务器节点 100.120.230.0 在同一网络里；`tailscale ping 100.120.230.0`，确认能通，记下结果。
5. 如果哪一步报错，记录实际报错就停下，不要改用别的办法绕过去。

**输出要求**

写 `tasks/done/T20261115-002.md`，包含：001 当前账号与节点 IP、Tailscale 是否已装、授权链接是否已发给用户、授权后 `tailscale status` 与 `tailscale ping 100.120.230.0` 的结果。只贴小段命令输出，禁止贴密钥、配置值、密码。

本仓库是公开仓，凭据与内部路径不写入。只做 001 本机 Tailscale 操作，不部署生产。
