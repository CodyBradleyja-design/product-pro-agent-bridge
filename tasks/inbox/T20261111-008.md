# T20261111-008｜万网/阿里云账号侧网站托管核查（只读）
优先级：高
背景：用户确认 fuloe.com 域名在万网（阿里云）购买，网站为 WordPress；用户目前无法登录 WordPress 后台，要求优先从万网/阿里云侧查清网站托管位置及可操作路径。
目标：利用用户本机已登录且明确授权的阿里云/万网控制台会话（若存在），只读确认域名和网站托管产品关系，为后续恢复WordPress后台或从主机侧管理提供依据。

执行要求：
1. 先检查当前本机浏览器是否已有用户主动登录的阿里云/万网控制台页面；没有则不要尝试登录、不要索要或保存密码/验证码/二次验证代码。
2. 如已有授权会话，只读检查 fuloe.com 对应域名详情、DNS解析记录、NS、域名状态/到期日（敏感字段脱敏）；检查该账号下是否存在与网站相关的ECS、轻量应用服务器、虚拟主机/云虚拟主机、对象存储、CDN、建站产品或备案记录。
3. 明确区分“域名注册商”“DNS托管”“网站主机/WordPress托管”，不可因域名在万网购买就推断主机也在阿里云。
4. 查找网站主机IP/CNAME目标与阿里云产品实例的对应关系；若指向第三方主机，记录供应商线索并建议恢复对应WordPress管理员访问。
5. 若 WordPress 后台登录失败，提出安全恢复路线：确认站点类型（WordPress.com或自托管）、管理员邮箱/账号恢复、主机控制台/数据库备份恢复选项；不得绕过登录或直接改数据库密码。
6. 严禁更改DNS/NS/A/CNAME/MX/TXT、域名锁定/转移、续费、主机配置、WordPress文件/数据库、安装插件、购买/充值、发布或迁移。
7. 输出 reports/T20261111-008-aliyun-wanwang-readonly.md，列出已核实/未知、证据截图位置（不含账号隐私）、托管归属判断、恢复后台最安全路径、下一步需用户批准的动作。
