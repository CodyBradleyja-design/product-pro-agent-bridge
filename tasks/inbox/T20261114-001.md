# 【任务卡】T20261114-001 FULOE 产品库与客户部本机同步试跑

**任务目标**  
在微信所在的 Windows 电脑上，复用 FULOE 现有工作台和已配置的本地微信读取工具，跑通产品库与客户部的独立更新。

**执行范围**  
现有 Windows 微信环境、FULOE 本地测试工程、已有本地读取工具和测试环境。可在隔离分支或副本中开发和试跑。

**输入材料**  
现有 FULOE 产品库和客户部、已配置的微信 CRI／CLI 或 WorkBuddy 导出工具、一个允许试跑的供应商群和一条允许试跑的测试会话。优先使用已有测试样本，缺少样本时在本机请求选择。

**执行要求**
1. 实测本机工具能读取的群图片、群笔记和会话字段，记录实际支持范围。优先复用现有索引和导出逻辑。
2. 产品库从一个测试群读取新增商品图，在测试库保留来源和日期，能查看缩略图。连续更新两次，第二次无新增时应增加零条。
3. 客户部在本机用一条测试会话生成上次联系时间和待回访提醒，验证重复更新不会产生重复提醒。聊天原文和客户身份信息留在本机。
4. 同一 Windows 同步程序主动领取两类任务。在测试版网页保留独立的“更新产品库”和“更新客户部”入口，验证手机登录后点击触发、电脑离线提示及恢复后继续处理。没有现成的受保护手机测试入口时，完成可测部分，并列出还缺的具体配置。公开 GitHub 只承载本任务卡与汇总状态，手机测试使用测试数据。
5. 如自动队列拒绝执行，记录实际拒绝原因，并保留任务供 WorkBuddy 本机人工运行。维持现有队列限制。

**输出要求**  
在完成区只回传读取能力、测试计数、通过或失败状态、阻碍与下一步。分开列出 Windows 验收和手机验收。

**注意事项**  
测试与生产隔离，保留原始数据和现有项目。产品图片、客户信息、聊天原文、凭据与内部路径不写入公开仓库。试跑不发送微信消息、不部署生产。百度地图店名缺失沿已有核查任务处理。

**优先级** 高  
**创建日期** 2026-11-14（北京时间）
