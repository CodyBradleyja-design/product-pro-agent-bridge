# 本地配置说明

本目录只存放非敏感配置说明和不含真实凭据的示例。

## 凭据要求

- 不要在此目录或任何仓库文件中保存 GitHub Token、密码、Cookie 或私钥。
- 本地代理应从操作系统安全凭据管理器或环境变量读取凭据。
- 不要把凭据写入命令行参数、普通日志或任务报告。
- 如果凭据曾被误提交，应立即撤销并轮换；仅删除文件不足以消除历史记录中的泄露。

## 初始配置项（由本地代理实现）

- 仓库：`CodyBradleyja-design/product-pro-agent-bridge`
- 分支：`main`
- 收件箱：`tasks/inbox/`
- 完成目录：`tasks/done/`
- 报告目录：`reports/`
- 轮询间隔：初始建议 600 秒（10 分钟），稳定后可改为 1800 秒（30 分钟）
- 时区：`Asia/Shanghai`

这些是实施约定，不表示本地 WorkBuddy 已经配置完成。
