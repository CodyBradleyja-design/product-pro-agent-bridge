## 二、四层实体标准设计（可直接落地）

设计原则：**沿用现有数据不改库结构**，新增关系层；旧索引保持只读，新表用 SQLite 本地起步，云端另议。

```
Style(标准款式) ──< Variant(规格) ──< Listing(商家上架) >── Store(商家)
        │                                     │
        └────────── Source(来源证据) ─────────┘
```

### 2.1 表结构（SQLite 起步，字段即云端迁移契约）

```sql
-- 标准款式：平台唯一，人工可控
CREATE TABLE style (
  style_id      TEXT PRIMARY KEY,      -- 例 S-HULU-0001，稳定不复用
  name          TEXT NOT NULL,         -- 葫芦 / 四叶草 / 素圈
  category_l1   TEXT NOT NULL,         -- 沿用现有 10 个一级类
  craft         TEXT,                  -- 工艺特征
  material      TEXT,                  -- 足金999 / 18K / 古法金
  shape_vec     BLOB,                  -- 向量索引（可为空，后续填）
  canon_img     TEXT,                  -- 授权标准图 ID
  version       INTEGER DEFAULT 1,
  status        TEXT DEFAULT 'active', -- active / merged / deprecated
  created_at    TEXT, updated_at TEXT
);

-- 规格：同形状不同规格绝不混并
CREATE TABLE variant (
  variant_id    TEXT PRIMARY KEY,
  style_id      TEXT NOT NULL REFERENCES style(style_id),
  size_mm       TEXT,                  -- 尺寸
  ring_size     TEXT,                  -- 圈口
  weight_g_min  REAL, weight_g_max  REAL,
  craft         TEXT, material TEXT,
  brand_auth    TEXT                   -- 品牌授权信息
);

-- 商家/店铺：地图 POI ≠ 已入驻
CREATE TABLE store (
  store_id      TEXT PRIMARY KEY,
  name          TEXT NOT NULL,
  addr_public   TEXT,                  -- 可公开经营地址
  lng REAL, lat REAL,
  phone_public  TEXT,
  verify_status TEXT DEFAULT 'unclaimed', -- unclaimed/claimed/verified/revoked
  license_no    TEXT,                  -- 营业资质（不公开）
  geo_source    TEXT,                  -- amap_api / baidu_api / self_submit / public_list
  geo_license   TEXT,                  -- 该坐标的授权依据
  claimed_by    TEXT, claimed_at TEXT,
  updated_at    TEXT
);

-- 商家上架：一个款多商家、一个商家多款
CREATE TABLE listing (
  listing_id    TEXT PRIMARY KEY,
  store_id      TEXT NOT NULL REFERENCES store(store_id),
  style_id      TEXT NOT NULL REFERENCES style(style_id),
  variant_id    TEXT REFERENCES variant(variant_id),
  actual_weight REAL,                  -- 商家自填实际克重
  price         REAL,                  -- 报价（非从 POI 推断）
  stock_status  TEXT,                  -- in_stock / preorder / out
  shop_img      TEXT,                  -- 商家实物图（授权上传）
  price_updated_at TEXT,               -- 展示必须带「最后更新时间」
  publish_state TEXT DEFAULT 'draft',  -- draft/review/published/unpublished
  source_type   TEXT,                  -- self_report / authorized_sync
  updated_at    TEXT
);

-- 来源证据：任何一个自动化结论都要能回溯
CREATE TABLE source (
  source_id     TEXT PRIMARY KEY,
  target_kind   TEXT,                  -- style / listing / store
  target_id     TEXT,
  origin        TEXT,                  -- group_note / wego / zhaojin / self_upload / map
  origin_ref    TEXT,                  -- 溯源索引编号（不回传原始链接）
  confidence    REAL,                  -- 匹配置信度
  human_fixed   INTEGER DEFAULT 0,     -- 是否人工纠错
  captured_at   TEXT
);
```

### 2.2 三条铁律（写进流程，不靠自觉）

1. **地图 POI 不得生成店铺，更不得生成 Listing**。POI 只能进 `store` 且 `verify_status='unclaimed'`、`geo_license` 必须非空才允许对外显示名称。
2. **价格 / 库存只来自商家自填或授权同步**，禁止从图片或 POI 推断；对外必须显示 `price_updated_at`，超 3 天显示「信息可能过期」。
3. **来源证据必须落表**，`confidence < 阈值` 的一律进人工复核队列，不进已发布状态。

### 2.3 商家认领 → 勾选「我有这款」→ 上架 的流程

```
地图/搜索命中 → 店铺页(unclaimed，仅公开信息)
   → 商家提交认领(营业执照/门店照/手机验证)
   → 平台审核 → verify_status=verified
   → 店铺后台按类目/造型浏览标准款 → 勾选「我有这款」
   → 补录：实际克重、圈口、工艺、可售状态、报价、实物图
   → 提交 → 平台审核(publish_state: review→published)
   → 消费者/同行按款式或地图查 → 看到"哪家店有这款、什么克重、什么价、什么时候更新"
```

增量更新策略：
- 商家后台支持单条改 + 批量导入（CSV/Excel 模板）。
- 每次改价/改库存写 `price_updated_at`，并留 `listing_history` 快照（可加表，非首版必须）。
- 全站按 `updated_at` 增量同步到云端，不在本地全量重建索引。
